# Project Structure - Warungio Marketplace

This document outlines the organized repository structure of the Warungio project.

```
project-web-s4/
├── django_backend/          # Core Django + REST Framework backend
│   ├── config/              # Main project configurations (settings, URLs, ASGI/WSGI)
│   ├── accounts/            # Accounts module (User logic, OTP, social auth, emails)
│   ├── stores/              # Store management module
│   ├── products/            # Product catalog and review module
│   ├── orders/              # Order management module
│   ├── payments/            # Payments integration (Midtrans)
│   ├── templates/           # Django templates
│   ├── static/              # Source static files (CSS, JS, images)
│   └── ...
├── docs/                    # Reorganized project documentation
│   ├── architecture/        # Architecture diagrams and blueprints (e.g., ARCHITECTURE.md)
│   ├── database/            # Database schema specs (e.g., Database.md)
│   ├── deployment/          # Deployment and infrastructure guides (e.g., DEPLOYMENT.md)
│   ├── CLEANUP-PLAN.md      # Cleanup guide
│   ├── Task_Roadmap.md      # Roadmap spec
│   ├── analisis-spec.md     # Technical analysis
│   └── warungio-spec.md     # Product specification
├── tools/                   # Reorganized maintenance, cleanup, and helper utilities
│   ├── _fix_login.py        # Login fix helper
│   ├── check_builds.py      # Build analysis tool
│   ├── check_logs.py        # Log analyzer
│   ├── cleanup_assets.py    # Asset cleanup utility
│   ├── find_large_django.py # Django app sizing analyzer
│   ├── fix_assets.py        # Mockup assets path fixer
│   ├── powershell.bat       # Runner helper (also kept in root for compatibility)
│   └── scaffold.bat         # Component template generator
├── logs/                    # Reorganized diagnostic and build text logs
│   ├── builds.txt           # Build status logs
│   ├── cloudrun_logs.txt    # Cloud Run output logs
│   ├── deploy_output.txt    # Deploy results logs
│   └── service_describe.txt # Cloud Run service description
├── backend/                 # Legacy PHP backend files (ARCHIVE ONLY)
├── assets/                  # Shared asset files (static CSS/JS/images)
├── shared/                  # Shared stylesheet/script framework files
├── auth/                    # Auth HTML templates
├── buyer/                   # Buyer dashboard HTML templates
├── seller/                  # Seller dashboard HTML templates
├── home/                    # Landing page HTML templates
├── src/                     # React/JS mockup source files
├── staticfiles/             # Collected static files (generated by collectstatic)
├── Dockerfile               # Production build instruction
├── docker-compose.yml       # Local orchestration services config
├── docker-entrypoint.sh     # Docker runtime startup script
├── cloudrun.yaml            # Cloud Run service deployment spec
├── .env                     # Local environment settings
├── .dockerignore            # Docker ignore patterns
├── .gcloudignore            # GCloud ignore patterns
├── .gitignore               # Git ignore patterns
└── README.md                # Project entry documentation
```
